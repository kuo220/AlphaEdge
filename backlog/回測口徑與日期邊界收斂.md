# 回測口徑與日期邊界收斂

## Abstract

- **背景／問題**：[全專案架構與邏輯健檢（2026-09）](../docs/dev/health-check-2026-09.md) S11~S14 在引擎、model、管理器與策略層抓到 17 條 B 級，共通點是**口徑或日期邊界與文件判準不一致但不會報錯**：SBL 借券費按 bar 而非曆日計提（F-059）、當沖減半稅率不看交易日（F-060）、成交價合理性只檢查開倉腿且在滑價前（F-064）、`get_last_trading_date()` 往前無界迴圈（F-065）、`OPEN_INTEREST` 換月會回頭（F-071）、同標的雙向持倉只擋一半（F-057）等。
- **目標**：每一條與 [放空框架](../docs/backtest/short-selling-framework.md)、[多市場引擎](../docs/backtest/multi-market-engine.md) 的判準對齊，並各有一條測試釘住；會改變回測數字的項目集中一次重產 baseline。
- **範圍界線**：不做事件驅動迴圈（§5.1）、不改報表欄位名、不做 per-instrument model。
- **驗收標準**：`pytest -m "not slow"` 全綠；`./scripts/run_regression.sh` 通過（會變動的步驟在同一批重產 baseline 並記錄 diff 原因）；每條 F 編號在附錄 A 的「處置」欄指向本文件的步驟。

## 步驟詳述

### S1. 成本與稅率的日期邊界 ⬜

- **目的**：F-059（SBL 每 bar 計 1/365，年費低估約 31%）、F-060（2017-04-28 前的當沖稅少一半）、F-063（`holding_days` bar 數 vs 曆日同名）。
- **做法**：`accrue_holding_cost()` 以「本 bar 日期 − 上次計提日」的曆日數計提；`core/utils` 新增 `DAY_TRADE_TAX_START = 2017-04-28`，`tax()` 增加 `date` 參數只在區間內減半；部位 `holding_days` 改記曆日或改名 `holding_bars`。
- **產出**：見進度表。
- **驗證方式**：兩條新測試；SHORT 快照重產並在 commit 訊息記錄 diff 原因。
- **相依**：無。

### S2. 成交路徑防線 ⬜

- **目的**：F-064（`validate()` 只看開倉腿且在滑價前）、F-037 殘餘（`high/low` 為 0 時跳過區間檢查，無成交日仍可成交）、F-022（tick 路徑 OHLC 全 0）。
- **做法**：`fill()` 之後對 `filled_order.price` 再做區間檢查並夾到 `[low, high]`；平倉腿超區間只警告＋新 key `close_price_out_of_range`；DAY 級別 `not quote.volume` 一律拒單；adapter 對 tick 路徑補 OHLC 或明確標記不可用。
- **產出**：見進度表。
- **驗證方式**：新測試；可能改變 LONG baseline（只在啟用滑價的策略），需記錄。
- **相依**：無。

### S3. 部位與帳務 ⬜

- **目的**：F-057（開多不檢查已有空單，§7.5「反之亦然」只做一半）、F-021（無報價退回開倉價算市值）、F-058（期貨同契約多空各佔保證金）、F-020（`check_has_position()` 未濾已平倉）。
- **做法**：`open_position()` LONG 分支補對稱檢查；`get_short_market_value()` 改退回前收；期貨對沖部位保證金依交易所規則只收單邊（可延後）；`check_has_position()` 補 `not is_closed`。
- **產出**：見進度表。
- **驗證方式**：「先空後多」測試；無報價市值測試。
- **相依**：無。

### S4. 交易日曆與資料缺口 ⬜

- **目的**：F-065（起始日前無資料即卡死）、F-028（缺日當休市）、F-066（每曆日 `SELECT *` 判空）、F-099（索引）。
- **做法**：`get_last_trading_date()` 加 30 曆日上界並 raise；`TwStockDataFeed.setup()` 一次建交易日集合；`MomentumStrategy1` 改用 `shift_trading_days()`；缺日偵測：回測起跑前比對交易日集合與 `price` 表，缺日一律 warning＋計數（根治在 ETL 文件 S4）；loader 建表時 `CREATE INDEX IF NOT EXISTS`。
- **產出**：見進度表。
- **驗證方式**：見進度表；LONG 回歸不變（只加防線與索引）。
- **相依**：無。

### S5. 換月與期貨結算 ⬜

- **目的**：F-071（`OPEN_INTEREST` 即時轉倉會回頭；展期價差混用結算價與收盤價）、F-070（日曆只看第一個商品）、F-069（近月拼接挑到週契約）、F-027（`get_margin_rates()` 例外語意不一致）、F-062（期貨損益公式兩套）。
- **做法**：`roll_positions()` 加 `active < position.expiry` 即跳過；轉倉兩腿同一種價；日曆改商品聯集；對標序列重用 `FuturesRollPlanner`；manager 改呼叫 cost model 的損益函式。
- **產出**：見進度表。
- **驗證方式**：`tests/test_futures_roll_backtest.py` 補反轉情境；期貨示範策略結果比對前後差異並解釋。
- **相依**：無。

### S6. 策略層 ⬜

- **目的**：F-072（`OvernightLeadEventStrategy` 建構即崩）、F-073（loader 任一模組壞即全壞）、F-086／F-087（研究 README 成本敘述與成品口徑）、F-075（TICK 未擋）、F-076（`max_holdings` 預設 0）。
- **做法**：`_build_signals()` 延後到 `setup_apis()` 之後；美股特徵改由 ETL 入庫；loader 逐模組 try/except＋重複類名 raise；README 成本段改寫、兩版共用訊號函式並補一致性測試；`scale != DAY` 即 `NotImplementedError`；`max_holdings` 預設 `None` 或 factory 檢查。
- **產出**：見進度表。
- **驗證方式**：見進度表。
- **相依**：無。

### S7. API 邊界 ⬜

- **目的**：F-024（`get_net_chip()` 呼叫簽章不符）、F-025（`datetime.date` 直接當 sqlite 參數）、F-026（表名 f-string 拼接）。
- **做法**：修簽章並補測試；`BaseDataAPI` 統一把 `date` 轉 ISO 字串；表名走白名單。
- **產出**：`core/api/tw/*.py`、`core/api/base.py`。
- **驗證方式**：`tests/test_stock_data_api.py` 擴充。
- **相依**：無。

### S8. analyzer 風險指標公式 ⬜

- **目的**：F-068（Sharpe 分子 % 分母小數、未年化、Sortino 公式、零筆除以零）。
- **做法**：改以 `daily_equity` 日報酬序列年化（√252）、無風險利率同單位；零筆回 `None`；與前端 [前端指標與報表同源化.md](./前端指標與報表同源化.md) 共用同一份公式（放 `core/backtest/analysis/`）。
- **產出**：`core/backtest/analysis/analyzer.py`。
- **驗證方式**：手算範例測試。
- **相依**：無。
